# Plugin

Plugins are small libraries that add new abilities to Jenkins and can provide integration points to other tools.

# Plugin Installation steps

click on **Manage Jenkins**

![Alt-text](https://github.com/herrry107/Jenkins/blob/main/images/jenkins-manage-jenkins.png)

click on **Manage Jenkins -> plugins**

![Alt-text](https://github.com/herrry107/Jenkins/blob/main/images/jenkins-manage-jenkins-plugin.png)

click on **Manage Jenkins -> plugins -> Available Plugins**

![Alt-text](https://github.com/herrry107/Jenkins/blob/main/images/jenkins-manage-jenkins-plugin-available.png)

click on **Manage Jenkins -> plugins -> Available Plugins -> Search**

![Alt-text](https://github.com/herrry107/Jenkins/blob/main/images/jenkins-manage-jenkins-plugin-available-ansible.png)
